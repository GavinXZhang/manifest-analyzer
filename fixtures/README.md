# Manifest fixtures

Realistic manifest files used by the ingestion tests, each modeled on a
different seller's real B-Stock manifest layout:

- `techliquidators-electronics.csv` — the "standard" layout the spec's
  zero-config scenario targets: `Item Description, UPC, Qty, Unit Retail, Condition`.
- `homegoods-returns.csv` — non-standard column names (`Prod Desc`, `Pcs`,
  `Est. MSRP`, `Cond.`, `Dept`) that push auto-mapping below the confidence
  threshold and trigger the mapping-confirmation flow.
- `amazon-returns.xlsx` — ASIN-keyed manifest with a junk title row above the
  header and rows with missing identifiers (unverifiable-row flagging).
  Generated by `npm run fixtures` (`scripts/make-xlsx-fixture.ts`).

These are hand-built to match real layouts, not copies of any seller's actual
manifest data. To test against your own downloads, drop real manifest files in
here and upload them through the UI — nothing in the app is fixture-specific.
